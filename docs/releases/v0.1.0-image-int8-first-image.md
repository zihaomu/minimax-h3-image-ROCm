# v0.1.0-image-int8-first-image

冻结日期：2026-11-13。此 tag 保存 MiniMax-H3-Image 在单张 Radeon AI PRO R9700 上的首个完整 INT8 文生图请求：**2048×2048、6 步、CFG=1，工作流耗时 17.642 秒**。

测量来自已完成的 `p2-first-image-2048-r2`。这是一次包含诊断记录的功能观测；无 profiler 热请求、吞吐、重复性、TP2、四卡、4K 和原生 BF16 精度均未取得验证资格。发布时未重新运行 GPU 测速。

## 工作量与环境

| 项目 | 固定配置 |
|---|---|
| 硬件 | 1 × Radeon AI PRO R9700，gfx1201；原运行物理 GPU1 |
| 图片 | 2048×2048，batch 1，seed 42 |
| 采样 | 原生六步，CFG 1，euler/simple，denoise 1 |
| 输入 | [固定工作流](../../configs/workflows/t2i_2048_api.json)中的狐狸毛绒玩具、蓝色杯子和黄色花朵详细 prompt |
| 权重 | DiT / 编码器 INT8 ConvRot；图片 VAE FP16 |
| 引擎 | 原生 ComfyUI v0.45.0 `PromptExecutor`；提交 `989d93d0d968e704c589ce0146bb18c77f6b50cc` |
| 基础环境 | ROCm 10.1.0；Torch `2.14.0+rocm10.1.0`；Triton `3.8.0+git669b31ac.rocm10.1.0` |
| 加载策略 | 原生 DynamicVRAM 与异步权重卸载开启 |
| 执行策略 | Comfy 编译器、节点结果缓存和 prompt expander 关闭 |

INT8 是权重格式及部分算子路径，实际计算包含浮点操作。此版本不能用于证明不量化或禁止 CPU offload 的目标已经完成。

## 耗时与显存

| 指标 | 单次观测 |
|---|---:|
| 完整工作流请求 | **17.641758 秒** |
| 文本 conditioning，含阶段加载 | 5.273793 秒 |
| KSampler，含加载和诊断记录 | 9.293759 秒 |
| VAE decode，含阶段加载 | 1.673192 秒 |
| PNG 保存节点 | 0.497275 秒 |
| 整卡 VRAM 采样峰值 | 31.618 GiB |
| 进程 RSS 峰值 | 2.857 GiB |

完整请求计时从执行器调用至图片保存完成并同步 GPU，排除容器与应用启动。请求包含节点边界同步、张量保存、dispatch 计数和相关节点首个 SDPA 调用的 CPU profiler。各阶段数值不是纯 kernel 时间，也不能直接相加替代完整请求耗时。

仅有一个成功样本，没有热请求中位或并发吞吐统计；此前中断尝试已影响文件系统缓存，因此没有冷存储延迟结论。整卡显存约每两秒采样，观测峰值为 33,949,990,912 bytes；Torch allocator 不覆盖全部 DynamicVRAM 权重分配。

## 验证范围与复现

原请求正常完成，保存六步记录与 2048×2048 PNG；已保存张量通过有限值检查，目视检查无空白或损坏。输出 PNG SHA256：

```text

```

完整输入 A/A、多 prompt、多 seed、无 profiler 热请求、编辑、原始 BF16 对照及多卡验证待执行。首图不构成通用画质或量化无损证明，也不承诺其他运行环境能复现相同时间或 PNG 字节。

在已配置共享 ROCm 10.1 foundation、固定依赖和上述模型的工作区，切到此 tag 后，使用一个新运行目录复现诊断请求：

```bash
git fetch origin tag v0.1.0-image-int8-first-image
git switch --detach v0.1.0-image-int8-first-image
python3 tools/run_rocm10.py --gpu 1 --run-dir runs/reproduce-v0.1.0-image-int8-first-image -- .runtime/venv/bin/python tools/run_image.py
```

执行时仍需通过共享预约和设备归属检查，GPU3 排除；详细前置条件见 [QUICKSTART](../QUICKSTART.md)。发布只包含源码、配置和整理后的文档；`vibe/`、`research/`、权重、环境、原始张量、图片和运行日志继续保存在本地。
